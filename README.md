# arduino_projects
Разные проекты на Ардуино

1) VL53L0X_counter.ino
С помощью TOF-датчика считает вылетающие из станка детали. На 4000 штук делает отсечку. Выводит на дисплей текущее состояние. При каждом подсчете издает звуковой сигнал. Используется в проекте счетчика деталей на производстве. 

2) exohand_control.ino
Простая система управленя 3-мя сервоприводами с помощью миниатюрного пульта на радиоуправлении. Используется в прототипе бионической экзокисти.

3) vl53l1x_vibro_range.ino
С помощью TOF-датчика измеряется расстояние до объекта и соответственно меняется частота оборотов вибромотора. Чем ближе объект, тем чаще вибрирует мотор. Используется в проекте инфракрасного дальномера для незрячих.
